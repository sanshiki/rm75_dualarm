# RM75 Single Manipulation

RLDS dataset builder for single-arm RM75 teleoperation episodes.

Source episodes are generated by `rlds/utils/npy_convert.py` from ROS 2 bags.
Each source `episode.npy` contains a list of step dictionaries with RGB images,
end-effector delta actions, poses, joint state, gripper command, and a language
task description.

Default raw data layout:

```text
data/
  train/**/episode.npy
  val/**/episode.npy
```

The builder emits RLDS episodes with primary and wrist RGB observations, a
15-D robot state, a 7-D source action, RLDS step flags, reward, discount, and
language fields.
